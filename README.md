# Feature-Extraction-using-Python
This project prepares textual data for machine learning models (like Naïve Bayes, SVM) to classify messages as spam or not. The Bag-of-Words model enables machines to process and analyze textual information efficiently.

# SMS Feature Extraction with NLP and Bag-of-Words
This project preprocesses SMS text data for spam detection using Natural Language Processing (NLP).

## Features:
- Text Cleaning (Lowercasing, Punctuation & Stopword Removal)
- Tokenization & Vectorization using CountVectorizer
- Bag-of-Words (BoW) Model for Feature Extraction
